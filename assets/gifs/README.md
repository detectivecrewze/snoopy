# GIF slots

The supplied Snoopy animations are stored locally here as animated WebP files:

- `welcome.webp` — opening screen
- `wish-writing-top.webp` — shown above the wish form while the recipient writes
- `wish-new.webp` — after the candle is blown out
- `hug.webp` — warm wishes page
- `dance.webp` — music page
- `cozy.webp` — homepage decoration
- `memories-logo.webp` — Our Memories card logo
- `letter-logo.gif` — A Letter card logo
- `letter.webp` — bottom of the letter
- `finale.webp` — final birthday screen

All animations are loaded from this folder instead of hotlinked from Tenor, keeping the gift reliable when shared. Their combined size is under 800 KB.
